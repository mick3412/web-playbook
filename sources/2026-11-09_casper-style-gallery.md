## 摘要（以自己的話整理）

- 工作流：主對話先為每種風格寫一份 SKILL.md，再派子代理依該技能產出單檔網頁（≤ 200 KB），最後截縮圖、錄 3 秒預覽。
- 規模：26 種靜態風格、15 種動效（視差、滾動、入場、循環、指標）、17 種手機 App 介面，共 58 份。
- 固定契約：內容 brief 對子代理唯讀；9 個區塊的順序與 id 固定；驗證腳本檢查區塊齊全、名稱和價格一字不差；另有截圖、抓 console 錯誤的腳本。
- 單份 SKILL.md 的結構（以極簡為例）：風格理念與三個辨識特徵 → CSS 變數（色、間距、圓角、字型）→ 字級表 → 版面規則 → 各區塊構圖 → Do／Don't 表 → 輸出契約（區塊齊全、對比 ≥ 7:1、三斷點、手機留白下限、重點色出現次數上限）→ 圖片清單 → 參考 CSS 片段。
